# Бриф · Софья

Пошаговая анкета на 7 этапов с отправкой в Telegram.

## Особенности этой версии

- Заявки приходят в **тот же чат**, что и основной бриф
- Заголовок сообщения — **«Новый бриф от Софи»**, чтобы было видно, чей бриф и кому переслать
- Используется **тот же Cloudflare Worker** — настраивать ничего не нужно

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Разметка |
| `styles.css` | Оформление |
| `app.js` | Логика: этапы, валидация, черновик, файлы |
| `config.js` | Адрес приёмника и заголовок заявки |
| `worker.js` | Код Cloudflare (уже развёрнут, менять не нужно) |

## Как поменять заголовок заявки

В `config.js`:

```js
PROJECT_NAME: 'Новый бриф от Софи'
```

Это то, что вы видите первой строкой в Telegram.

## Как поменять вопросы

Массив `STEPS` в начале `app.js`:

```js
{ id:'b1',
  label:'Текст вопроса',
  hint:'Подсказка',      // необязательно
  required:true,          // обязательное поле
  key:true,               // плашка «важно»
  type:'text' }           // 'text' — одна строка
```

## Контакты в подвале

Telegram Софьи — `@fox_sm_1`, меняется в `index.html` поиском по этой строке.
